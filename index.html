 Create disbursement note

      
    

    

      

        What is a Disbursement Note?
        A Disbursement Note (DN) is raised by the warehouse to authorise the release of stock to a clinic branch. The receiving clinic must then raise an Acknowledgement Receipt (AR) to confirm receipt.
      

      

        

          
        

        

          
        

      

      

        

          
        

        

          
        

      

      

        
      

    

    

      
      
    

  







  

    

      
 Create return note

      
    

    

      

        What is a Return Note?
        A Return Disbursement Note (RDN) allows a clinic to return stock to the warehouse — for example, expired batches, excess stock, or damaged items. The warehouse acknowledges via a Return Acknowledgement Receipt (RAR).
      

      

        

          
        

        

          
        

      

      

        

          
        

        

          
        

      

      

        

          
        

        

          
        

      

      

        
      

    

    

      
      
    

  







  

    

      
 Record stock adjustment

      
    

    

      

        
        Manual adjustments create an immutable entry in the Stock Ledger with reference type Manual Adjustment. Use only for corrections that cannot be captured via a shipment or return.
